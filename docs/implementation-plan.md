### PR #17 security fix

Replaced Host-based loopback authorization with a required trusted peer argument from the custom server's `req.socket.remoteAddress`, carried through the transport and both access checks. Only `127.0.0.1`, `::1`, and `::ffff:127.0.0.1` qualify. All frame uploads, including local scripts, require an exact Origin matching the server-configured canonical `http://localhost:<PORT>` origin; missing and `null` origins are rejected.
